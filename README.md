# A/B Testing: Optimizing Retention in Cookie Cats

## 📌 Overview
This project analyzes an A/B test from the Cookie Cats mobile game to evaluate whether moving a level gate from 30 to 40 impacts player retention.

## 🎯 Objective
Determine if the change improves retention using statistical hypothesis testing.

## 🧪 Methodology
- Data cleaning & exploration
- Retention analysis (Day 1 & Day 7)
- Hypothesis testing (Z-test)
- Interpretation of statistical results

## 📊 Key Findings
- No statistically significant difference (p-value = 0.07)
- Retention is slightly higher for gate_30

## 💼 Recommendation
Keep the gate at level 30. There is no strong evidence that moving it to level 40 improves retention.

## ⚠️ Limitations
- Short observation window (7 days)
- Only retention analyzed (no revenue data)

## 🚀 Next Steps
- Analyze longer-term retention (Day 30)
- Segment users by engagement level
- Include additional metrics like revenue
